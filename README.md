# Oi, eu sou o Igor Marinho 👋

**Desenvolvedor Backend Sênior** · C#/.NET, Node.js e AWS · Engenheiro civil de formação

## 🤔 Quem sou eu?

Sou desenvolvedor backend sênior na **Welcome the Future (WTF)**, onde sou a referência técnica de uma plataforma omnichannel multi-tenant (chatbot, WhatsApp, e-mail e voz) em C#/.NET na AWS. Decido a arquitetura do código, faço code review e mentoro desenvolvedores júnior e estagiários.

Vim da engenharia civil, com atuação em grandes obras como a Arena Fonte Nova e o Metrô de Salvador, e trouxe de lá planejamento, relacionamento com o cliente e o hábito de entregar no prazo. Sou graduando em Sistemas de Informação (UFBA), formado em Desenvolvimento Web Full Stack pela Trybe, membro da TITAN (Empresa Júnior de Engenharia da Computação da UFBA) e tenho inglês fluente. Fora do código, gosto de nadar e cozinhar.

## 🛠️ O que faço no dia a dia

- **Arquitetura:** APIs em camadas, CQRS com Mediator, multi-tenancy e providers desacoplados.
- **Qualidade:** migrations com EF Core, análise de vulnerabilidades (Trivy), testes automatizados e mais de 4.500 warnings, vulnerabilidades e erros resolvidos.
- **Cloud e CI/CD:** AWS, GitHub Actions, Docker e Redis.
- **Dados:** PostgreSQL, MongoDB e MySQL.
- **IA no processo:** desenvolvimento assistido por IA e orientado a especificações.
- **Full stack:** front-end em Vue.js, React e Next.js quando o projeto pede.

## 📌 Projetos em destaque

- [calculadora_acb](https://github.com/IgorMarinhoArgollo/calculadora_acb): calculadora de custos de arbitragem da Associação Comercial da Bahia, feita para um cliente real.
- [trybe-soccer-club](https://github.com/IgorMarinhoArgollo/trybe-soccer-club): API REST em TypeScript para a classificação de um campeonato de futebol (JWT, Sequelize, MySQL, Docker e testes de integração).
- [store-manager](https://github.com/IgorMarinhoArgollo/store-manager): API REST de gestão de loja em Node.js, Express e MySQL, com Swagger, Docker e testes unitários.
- [talker-manager](https://github.com/IgorMarinhoArgollo/talker-manager): API REST para gerenciar palestrantes de um evento, com autenticação por token, CRUD e documentação Swagger.
- [recipe-app](https://github.com/IgorMarinhoArgollo/recipe-app): app de receitas de comidas e bebidas em React, feito em equipe com metodologias ágeis.
- [trivia-game](https://github.com/IgorMarinhoArgollo/trivia-game): jogo de perguntas e respostas com React e Redux Toolkit.
